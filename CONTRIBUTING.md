# Contributing to dw Secret Notes

Solo-developer open-source project — contributors welcome.

**App:** Android, end-to-end encrypted self-destructing notes + images, AES-256, 15 languages. Think Privnote with a native app and image support.
- Play Store: https://play.google.com/store/apps/details?id=com.snote.domezos
- Web: https://domezos-ware.com

## Help wanted

- Android / Kotlin — features, bug fixes, code review
- UI/UX — functional but always room for improvement
- Security audit — crypto implementation review welcome
- Translations — 15 languages, more welcome
- Backend (PHP/JS) — `WebApp/` directory

## How to contribute

1. Read [README-EN.md](README-EN.md) for architecture overview.
2. Open an Issue first — describe what you want to fix or add.
3. Fork, create a branch, submit a Pull Request.
4. PR review within ~48h (side project, bear with me).

Check [Issues](https://github.com/domezos2024/dw-secret-notes/issues) for `good-first-issue` tags.

Questions? Open an Issue or GitHub Discussion.
