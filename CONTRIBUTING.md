# Contributing to snote.domezos Secret Notes

**Welcome!** This is a solo-developer open-source project and I'm looking for contributors.

---

## What is this?

An Android app that sends end-to-end encrypted notes and images that self-destruct after 60 seconds. Think Privnote but with native Android app, image support, AES-256 encryption, and 15 languages.

- Play Store: https://play.google.com/store/apps/details?id=com.snote.domezos
- Web: https://domezos-ware.com

---

## I'm Looking For Help With

- [] \u002a **Android / Kotlin developers** -- features, bug fixes, code review
- [] **UI/UX feedback** -- the app is functional but UX can be improved
- [] **Security audit/ review** -- if you know crypto, please review the encryption implementation
- [] **Translations** -- the app supports 15 languages, more are welcome
- [] **Documentation** -- improve the README, add architecture docs
- [] **Backend (PHP/JS)** -- the server-side handles note storage & destruction

---

## Tech Stack

- **Android**: Kotlin, Jetpack Compose
- **Backend**: PHP/JavaScript (WebApp/ directory)
- **Encryption**: AES-256

---

## How to Contribute

0. Read [README-EN.md](README-EN.md) for architecture overview
1. Open an Issue first -- describe what you'd like to fix or add
2. Fork the repo, create a branch
3. Submit a Pull Request
4. I review PR normally within 48h -- this is a side project so bear with me
